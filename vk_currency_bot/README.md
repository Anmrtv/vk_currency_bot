\# VK Currency Bot



Бот для конвертации валют.



\## Поддерживаемые валюты

\- евро

\- доллар

\- рубль



\## Команды

\- /start или /help — инструкция

\- /values — список доступных валют



\## Пример использования

евро доллар 100



\## Запуск бота

1\. Установите зависимости:

pip install -r requirements.txt



2\. Создайте config.py с токеном VK



3\. Запустите бота:

python main.py
